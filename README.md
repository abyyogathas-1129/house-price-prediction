# House Price Prediction

This project uses a machine-learning notebook to explore housing data, train a house-price prediction model, and generate predictions.

## Project Structure

- `data/`: training and test datasets
- `notebook/house_data_predict.ipynb`: analysis and model workflow
- `submission.csv`: generated prediction output
- `requirements.txt`: Python dependencies

## Setup

Create and activate a virtual environment, then install the dependencies:

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Open `notebook/house_data_predict.ipynb` in VS Code or Jupyter to run the workflow.
